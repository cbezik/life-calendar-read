Privacy policy

life calendar read is a personal tool used only by its owner, on their own computer.

What data it accesses

Events on the Google calendars its owner chooses, through the read-only Google Calendar permission (calendar.readonly), and the events it places itself on one calendar the owner owns, through calendar.events.owned. It requests no other Google data.

How the data is used

Events are read twice a day to find the owner's free time, so the owner's own to-dos can be placed there as events on the owner's own calendar, and moved when one is not done. The data is not used for advertising, profiling, training AI models, or any other purpose.

Storage and sharing

Nothing is sent to any server run by this tool; there is none. Calendar data stays on the owner's computer and is never sold, shared or transferred to anyone. The sign-in token is kept in the operating system's credential store, not in a file.

Google API Services User Data Policy

This tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/connections.
