life calendar read

A personal tool, run by one person on their own computer, that reads their own Google Calendar so their daily planning note can show the day's appointments.

What it does

  • Once a day, it reads upcoming events from calendars the owner chose, using the read-only Google Calendar permission (calendar.readonly).
  • It never creates, changes or deletes calendar events, and asks for no other Google data (no mail, no files, no contacts).
  • It is not offered to anyone else. There is no sign-up and no other user.
